# Fuzzle

Fuzzle is a simple clone of Boggle for the browser.

Many other Boggle clones are either bad, boring, filled with ads, or any mix and mash of those 3.
Meanwhile this one is fully free to play, no ads, and you can even play with a bot that is humanly impossible to beat! (feel free to prove me wrong >;3)

## How to Use

You can either download this repository and open [`/frontend/index.html`](/frontend/index.html),
or simply by going to [the Vercel-deployed page](https://fuzzle-game.vercel.app/).

## Repository Structure

The README and the license are located under the project root.
The source code for what you see is located under [`/frontend`](/frontend).
When the server is created, the source code for the server will be located under [`/backend`](/backend).
